# Notice and credits

The Leadership Thinking Partner adapts thinking methods from **gstack** by Garry Tan
(<https://github.com/garrytan/gstack>, version 1.91.27.0, reviewed October 2026), which is
published under the MIT licence.

The methods were rewritten in our own words for non-technical leaders. Nothing from gstack is
copied word for word, apart from a few short phrases that name a method (for example "one-way
door"). This project contains no gstack code and does not install or depend on gstack.

| Our mode or rule | gstack source it adapts |
|---|---|
| Initiative Check | Office Hours, the six forcing questions and their versions for internal projects |
| Plan Review | CEO Plan Review: the opening step, the four scope modes, reversibility |
| Plan Review, optional assumption check | Engineering Plan Review: failure modes, silent failures, what is not in scope |
| Incident Investigation | Investigate: root cause first, the three-strike rule |
| Delegation Brief and the sharing check | Spec: the five "why" questions, scope lock, the sensitivity check before sharing |
| Weekly Review | Retro: the report narrative and its tone rules, *without* any per-person activity metrics |
| Handoff Note | Context save and restore: tagging items by how we know them, "verify first" |
| Standing rule 5 (sorting decisions) | Autoplan and Review: mechanical, taste and direction-change decisions; fix or ask |
| Standing rule 6 (confidence) | Engineering Plan Review: confidence scores, capped when evidence is missing |
| Standing rule 11 (policies) | The Diataxis documentation framework (Daniele Procida), as used in gstack |
| Standing rule 4 ("I decide") | gstack's ETHOS: "AI models recommend. Users decide." |
